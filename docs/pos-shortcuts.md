# POS keyboard shortcuts

ATE05 keeps the high-frequency POS shortcuts deliberately small so keyboard use complements touch and pointer operation.

| Shortcut                 | Action                                                         |
| ------------------------ | -------------------------------------------------------------- |
| `Ctrl+K` / `Cmd+K`       | Focus menu search.                                             |
| `Escape` while searching | Clear the menu search and keep focus in the search field.      |
| `Enter`                  | Activate the focused button or submit the focused form action. |
| `Space`                  | Activate the focused button or toggle.                         |
| `Tab` / `Shift+Tab`      | Move through controls in document order.                       |

Shortcuts are ignored while typing in an unrelated input, textarea, select, or editable field. All actions remain available through labelled controls, and the application does not override standard browser or operating-system shortcuts beyond the search command.
